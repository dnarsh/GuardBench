## How to read this

- `hunk-all` finds every defect by construction (recall 1.000) and alarms on every clean twin; only precision, F1 and the alarm rate separate it from a useful reviewer.
- `random` shows the localisation floor: with 8 or more hunks it rarely lands on the defect.
- The toy script is a 40-line heuristic that looks for removed guard keywords. How much it finds measures how much of the benchmark is solvable by planted-bug style artifacts (a deleted `raise`, `return False` flipped to `return True`), not reviewing skill.
- Intervals are Wilson 95%; with 30 dev and 100 held-out pairs they are wide, and the per-class cells (6 dev, 20 held-out pairs) are wider still.
- Limits: synthetic defects written by one AI agent, cosmetic generated noise, public READMEs and tests that hint at each rule, held-out noise that is reproducible from public tools. See the README and `prereg/AMENDMENTS.md`.
