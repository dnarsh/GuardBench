# Provenance

All files in this repository (harness, apps, defects, noise pools, specs, tests, documentation,
pre-registration, amendments, written reviews) were written by an AI coding agent (Claude Sonnet 5.5
via Claude Code). The repository owner directed the work, set the design, and reviews it. Commits
carry a `Co-Authored-By` trailer for the agent.

The apps were written from scratch for this benchmark; no code was copied from existing projects.
The held-out items live in a separate private repository and were produced by the same agent with
the same tools, so they are not independent of the public dev items in style.

Nothing here is validated by an independent human author yet, and the written differential review
of the validator (`docs/reviews/`) is a self-review by the author agent. Both are threats to
validity (see the pre-registration and `prereg/AMENDMENTS.md`).

## Milestone 3 (v0.2.0)

Apps 13 to 20, their tests, 95 new defect specs (10 dev, 85 held out), the noise generator, the
streaming command reviewer, the toy example reviewer, the report generator and the written review were
again written by the same AI agent (Claude Sonnet 5.5 via Claude Code), working autonomously from a
brief by the repository owner and committing as the owner's identity with a `Co-Authored-By` trailer.
Noise pools of the seven new held-out apps are generated by the public `tools/gen_noise.py`. The 100
held-out items live in the private repo and share authorship, style and tooling with the public dev
items, so the split is not independent. No independent human has reviewed any app, defect or test, and
the written review (`docs/reviews/command-reviewer-and-example.md`) is a self-review. No model was run
on the benchmark and no API key was used.
