# Provenance

All files in this repository (harness, apps, defects, tests, documentation, pre-registration) were
written by an AI coding agent (Claude Sonnet 5.5 via Claude Code). The repository owner directed the
work, set the design, and reviews it. Commits carry a `Co-Authored-By` trailer for the agent.

The apps were written from scratch for this benchmark; no code was copied from existing projects.
Nothing here is validated by an independent human author yet, which is a threat to validity
(see the pre-registration).
